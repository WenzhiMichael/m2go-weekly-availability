# M2GO 员工班表

这是 M2GO 用来收集员工下周可上班时间、由经理安排并发布正式班表的内部工具。

## 员工使用方式

- 员工第一次使用经理发送的一次性链接，自己设置四位 PIN。
- 以后在员工首页选择自己的姓名并输入 PIN；同一台手机会保持登录 30 天。
- 员工只能读取和修改自己的下周可上班时间。
- 周一至周五可选择 `11-6`、`6-C`、全天 `11-C` 或自定义时段。
- 周六、周日可选择 `11:30-6`、`6-C`、全天 `11:30-C` 或自定义时段。
- `C` 代表当天午夜 `12:00 AM`。
- 经理发布后，员工可以查看完整正式班表；经理草稿不会提前显示。

## 经理使用方式

经理通过 `/manager` 和六位 PIN 登录，可以：

- 查看八位员工提交的下周时间。
- 在同一张表中点击选择最终上班人员。
- 查看完整可上、部分可上和冲突安排提醒。
- 发布或重新发布正式班表。
- 修改员工姓名，生成或重置员工专属链接。

员工忘记 PIN 时，经理生成新的设置链接；旧 PIN、旧链接和旧登录会立即失效。
PIN 只保存加密摘要，经理无法查看。连续输错五次后暂停登录 15 分钟。
一次性链接只在生成时显示，应当马上复制并通过私人消息发送。

## 每周运行

- 员工页面同时显示当前周正式班表，并收集下一周可上班时间。
- 经理默认安排下一周，也可以向前查看历史记录。
- 每周一按 `America/Toronto` 时区自动进入新周期。

## 在这台电脑启动

双击 `启动M2GO.bat` 或 `Start-M2GO-Schedule.cmd`，然后打开：

- 员工入口：`http://localhost:3000`
- 经理入口：`http://localhost:3000/manager`

本地数据保存在项目的 `.wrangler` 目录。经理密钥保存在 Windows 本机的
`%LOCALAPPDATA%\M2GO\manager.env`，不会放进 OneDrive 或上传到 GitHub。

## 配置新的经理 PIN

运行下面的命令，把 `654321` 换成新的六位数字：

```powershell
node scripts/create-manager-config.mjs 654321 --write-local
```
